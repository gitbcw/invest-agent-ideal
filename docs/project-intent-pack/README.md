# Project Intent Pack

这是一份从现有项目材料中抽离出的、实现无关的业务意图规格。

用途：
- 给后续 Agent 重新设计或重实现时使用
- 保留业务目标、功能标准、经验和边界
- 不复制旧代码结构，不把历史实现当成未来需求

文件顺序建议：
1. `00-summary.md`
2. `01-system-intent.md`
3. `02-business-architecture.md`
4. `03-feature-specs.md`
5. `04-implementation-standards.md`
6. `05-lessons-and-tradeoffs.md`
7. `06-do-not-inherit.md`
8. `07-open-questions.md`
9. `08-agent-guidance.md`
10. `09-wechat-bridge-appendix.md`
