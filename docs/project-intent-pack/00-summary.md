# Summary

这是一个微信优先的投资决策工作台，核心不是单次问答，而是把投资判断做成可记录、可复盘、可修正的闭环。

它要帮助用户完成四件事：
- 识别值得观察或持有的标的
- 为持仓生成次日预案
- 在盘中把条件触发变成提醒
- 在日/周/月复盘中验证前序判断并修正方法

核心约束：
- 不自动交易
- 不把服务层做成复杂意图路由器
- 不把未确认推测写成正式规则
- 不把旧代码结构当成未来业务结构
