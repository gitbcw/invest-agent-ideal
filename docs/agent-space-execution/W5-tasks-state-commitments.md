# W5：任务依赖、工作状态与承诺闭环

依赖：W1、W2、W4 契约；T-524 v2 状态语义有效。不得重写调度器。

任务仅由用户明确授权的持续工作创建，固定执行 Agent、触发、Skill/Method、输入输出、版本策略、交付与完成判据；修改形成新 revision，运行保存不可变 snapshot。执行成功、产物生成、投递成功、用户阅读分别记录。

Fact 引用已观察事实；Lesson/Workflow 草案、批准有效、拒绝/停用/替代和证据状态分离。draft 不注入，批准不代表正确。状态属于 conversation/task/agent；起始检索与补查共用硬预算、去重、冲突排除和解释记录。状态不能创建任务、写资产或通知。Commitment 是长期约定，run 是每期履约；关闭学习不取消既有授权任务。

验收：任务不扫描全量资产；拒绝不生效、批准只在适用范围复用；冲突/过期/停用/预算耗尽有记录；隔离验证两期履约、投递失败、暂停恢复；State Packet 不扩大权限且可被 W4 run-basis 查证。
