# W7：Owner 控制的真实切换与旧 Workspace 退出

依赖：W0-W6 独立验收，且 owner 指定用户、批次和维护窗口。否则禁止执行。

逐用户/逐对象：冻结 manifest hash → Workspace 外建立并验证备份 → 写入新对象 → 运行最小真实 smoke → 切换 resolver 到新对象 → 旧 Workspace 改为 history-only → 采集真实 run-basis/audit/任务交付证据。失败按批次回滚，不影响其他用户。

兼容窗口期间持续检查旧 default-load、双写和未迁移引用。只有 owner 明确批准且所有真实运行指向新对象、备份恢复可用、无未解决依赖、旧入口为零，才移除旧运行入口。物理删除历史不是默认目标，需另行授权。

报告必须列目标 scope、备份、导入版本、切换时间、真实依据、回滚、旧入口计数、任务/交付状态和用户反馈；部署成功或 Agent 自述不能替代接管证据。
