# W6：隔离迁移演练

依赖：W0-W5 全部验收。只用隔离 DB、隔离项目和受控真实内容副本；关闭微信、Portal connector、scheduler 和生产外部写入。

只接收 W0 中 `backupCoverage=covered`、非阻塞、有明确分类的项。源、备份、隔离副本、导入结果分目录并记录 hash。导入新对象并核对 scope、版本、引用、可见性；关闭隔离旧 Workspace `default-load`，对交互与任务生成 run-basis；回滚到导入前快照并验证。

必测：mg 四因子与 KP 独立且 KP 任务只拿 KP 绑定，不能将缺失模拟账本推断为空仓；111 日复盘模板与策略独立，一次性回测不变成长久方法；dyk 核心模型恢复可发现，撤回旧策略只归档，采用范围仍可阻塞。

验收：每项有源/目标 hash、ID/version、scope、引用；旧 default-load 关闭后新对象仍提供依赖；无跨用户/算法/版本污染；回滚成功；报告明确是隔离证据，不是生产切换。
