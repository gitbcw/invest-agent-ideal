## 业务判断

“是否应该有规则”在本轮只是覆盖推断，不是用户已确认的正式规则需求。因此不能把缺规则直接判定为系统缺陷，也不能把疑似僵尸规则直接删除。当前可以确认的是：规则资产与业务对象身份之间没有形成可审计的同步闭环。

这会造成两类风险：

1. 已不再关注或持有的对象可能继续产生提醒；
2. 当前真正需要观察的对象可能没有可验证的提醒通道。

在没有命中记录、误报记录和投递回执前，本轮不能判断实际噪声量或漏报量。
