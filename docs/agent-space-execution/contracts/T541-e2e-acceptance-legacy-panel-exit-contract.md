# T-541 实施契约：111 本地端到端验收与旧右侧面板退出准备（P4）

任务：os-mcp T-541（executor: hybrid——验收执行可由 agent 预跑，owner 终审）。前置：T-538、T-539、T-540 全部完成。
设计依据：[正式设计 §10.1/§11/§12](../../agent-space-user-product-design.md)；差距：[T537-gap-analysis U9](../T537-gap-analysis.md)。

## 目标

在 111 隔离环境完成整条产品路径的端到端验收（不是单模块验收），产出 owner 校对材料与旧右侧工作空间面板的退出方案（方案，非实施）。为「生产发布另立授权任务」提供完整决策输入。

## 输入

- T-538/539/540 全部产物与隔离环境（含构造的方法/Skill/失败反例/候选）。
- 现有聊天右侧面板：`apps/portal/src/components/chat/DocumentWorkspace.tsx` + `LibraryTree.tsx` + `workspace/files` API 链；会话附件预览能力（`FilePanelProvider`、附件卡片）。

## 工作内容

1. **端到端浏览器验收**（`scripts/agent-space/p0/e2e-acceptance.mjs` 或 playwright 脚本，全部走隔离环境）：
   - 侧栏五入口（待处理/自动化/我的文件/工作空间/设置）可达，工作空间默认方法 Tab 可切换；
   - 一条完整失败处理链：任务失败 → 待处理卡片 → 问题会话解释 → 候选提出 → 批准生效 → 对象页面确认；
   - 版本/生效分离抽查：编辑方法成新版本不改已绑定任务；Skill 未启用不影响运行；文件保存不触发任何生效；
   - 跨 scope 复核：全部新 API 以未授权 scope 冒烟（0 行或拒绝）；
   - 假投递复核：全链路无任何外发（OFFLINE 断言 + 隔离库投递失败记录检查）。
2. **产品验收清单人工走查**：按设计 §11「产品验收」逐条在浏览器确认（agent 预跑 + 记录截图/证据，owner 复核）。
3. **旧右侧面板退出方案**（文档，不实施移除）：
   - 盘点 DocumentWorkspace 当前承载的真实使用场景（会话内文件预览、附件查看、报告浏览）与替代路径（我的文件详情、附件卡片、报告页）的差距清单；
   - 给出移除步骤（含前端组件、workspace/files API 的去留）、需要保留的预览体验、迁移提示文案与回滚方式；
   - 明确「移除」本身属于生产发布授权任务范围，本契约只交付方案。
4. **验收报告**：`docs/agent-space-execution/T541-acceptance-report.md` —— 通过项、发现的设计/实现问题、修订建议、未覆盖证据（明确列出本地验证不能证明的事项，按设计 §11 证据边界分类）。

## 边界（红线）

- 不移除旧面板代码；不改生产；不批量改写任何真实用户资产。
- 验收发现的问题如实记录，不在验收任务内顺手大改（小修需在报告单列）。
- 生产发布建议只作为决策输入：目标、范围、迁移/备份/回滚边界、观察窗口由 owner 另行裁决（设计 §10.1 生产发布前置）。

## 验收

- e2e 脚本全过 + `npm test` 全绿 + verify-isolated 全过；
- owner 在隔离环境完成浏览器复核并给出明确反馈（通过/修订项清单）；
- 退出方案文档评审通过（替代路径无功能缺失或缺失项已列明取舍）；
- 验收报告就绪，包含生产发布建议清单。

## 失败与上报

- 端到端链路任一环节不通：记录阻断点并回溯对应前置任务，不在本任务内越界修复架构问题；
- owner 复核发现语义级设计问题：按设计 §10 P0 修订原则回写正式设计与底座契约，形成修订记录后再决定是否重跑相关分期。
