# T575：本人 `mirror-mg` 体验走查

日期：2026-10-07 09:08-09:12（Asia/Shanghai）  
环境：本地 `production-mirror` / `mirror-mg`；OFFLINE 模式；Portal `http://127.0.0.1:3120/chat`  
目的：验证“越用越好用”的初步用户体验，不评价收益，不把镜像结果当作生产结论。

## 结论

总体状态：`Pass with caveats`。

Skills 入口可以自然理解，预置技能和“已启用”状态清楚；“我的文件”能够看到方法、报告和历史资产，但对象类型、方法版本、采用/生效状态不够显性。一次全持仓只读复核请求已进入新的筛选数据准备编排，正确识别 14 只股票和 2 只 ETF；由于离线镜像没有行情 MCP，系统进入 `tools=none` 降级路径。约 115.8 秒后助手完成回传，正确区分服务记录、过期截图、行情缺口和行动状态，没有写入任何状态；但等待期间 Portal 没有显示处理中阶段或部分结果，因此用户体验仍为 `Partial`。

## 场景记录

### 1. Agent / Skill 入口

- 我想完成什么：确认当前助手有什么能力，以及哪些 Skill 正在生效。
- Agent 实际做了什么：Skills 页面展示 5 个预置 Skill，逐项显示说明和“已启用”；入口文案说明方法文件在“我的文件”管理。
- 困惑、等待或不信任：没有明显困惑；但“已启用”没有同时呈现版本或最近变更。
- 明显比以前好：不需要翻 Workspace 内部文件即可看到能力边界。
- 下一次希望怎么改：在技能详情中补充版本/更新时间，以及它是否影响当前运行。

判定：`Pass with caveats`。

### 2. 方法与资产入口

- 我想完成什么：找到当前采用的方法，并确认历史报告与方法文件的关系。
- Agent 实际做了什么：文件页展示方法、Skill 文件、报告、交付物和迁移资产，支持搜索和来源筛选。
- 困惑、等待或不信任：长列表把 `methods`、`skills`、`reports`、`deliveries` 和迁移路径并列展示；看不到一个直接的“当前采用版本/草稿/历史版本”状态。
- 明显比以前好：文件来源和路径可见，历史资产没有被隐藏或覆盖。
- 下一次希望怎么改：增加“方法/Skill/报告/历史资产”分类和当前生效版本标识；保留原始路径作为详情。

判定：`Partial`。

### 3. MG 全持仓只读复核

- 我想完成什么：基于当前持仓和关注对象筛选下一步值得关注的标的，不写入策略、持仓或提醒。
- Agent 实际做了什么：请求成功建立会话 `web_kxC2K8BN5rFVBu0d`，运行日志显示筛选数据准备识别 `stocks=14`、`etfs=2`；行情 MCP 连接失败后进入 `tools=none` 降级路径。
- 困惑、等待或不信任：发送后约 45 秒内 Portal 只有用户消息，没有助手结果、处理中状态或明确失败说明；直到约 115.8 秒才完成回传，用户难以判断是在等待、降级完成还是请求卡住。
- 明显比以前好：程序没有伪造当前行情，也没有写入投资状态；股票/ETF 分流和失败降级已被实际触发。
- 下一次希望怎么改：在长任务期间显示阶段状态和已取得证据；工具不可用时尽快返回“当前未知 + 已保留的历史事实 + 补证路径”，不要让输入区长时间保持无结果。

判定：最终内容 `Pass with caveats`；等待过程 `Partial`。

## 证据边界

- `npm run mirror:health`：runtime 200、Portal 307、relay 426，镜像启动通过。
- 服务日志：`筛选数据准备完成 conversation=web_kxC2K8BN5rFVBu0d stocks=14 etfs=2 tools=none`。
- 服务日志：`market-data-tool` 在 `127.0.0.1:8000` 连接失败；这是 OFFLINE 镜像预期的隔离边界，不是生产行情链路结论。
- `runtime.db` 最终写入 assistant 消息 1,818 字符；对应 trace 为 `glm-5.3-flash`、`success`、`elapsed_ms=115813`、`first_token_ms=4744`。走查前 45 秒的 Portal 界面仍没有可见 assistant 消息或处理中状态。

## 需要处理的问题

1. **P0 / Portal 交互**：长任务或降级路径没有稳定的处理中/失败/部分结果回显，用户无法知道下一步；本次实际等待约 116 秒。
2. **P1 / 上下文显性化**：方法和 Skill 的当前生效版本、草稿、采用和历史状态不够清楚。
3. **P1 / 离线体验**：工具不可用时应优先返回短的可用结论与缺口，而不是只保留后台日志。

暂不处理：不因本次体验新增业务级策略节点，不把镜像降级结果外推为生产数据能力，也不扩大更多行情编排。
