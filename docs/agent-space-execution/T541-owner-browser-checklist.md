# T-541 Owner 浏览器复核清单（MG 隔离环境）

## 目的

用浏览器确认新 Portal 对 MG 的真实历史、工作空间对象和失败处理流程是否可理解、可追溯且不误导用户。此清单只验收隔离环境，不构成生产发布授权，也不验证真实微信送达。

## 范围与边界

- 入口：`http://localhost:3110`，测试身份为 `primary`，其 scope 固定映射到 MG。
- 当前副本完全来自本地 `2026-09-22` 灾备中的 MG scope；本轮不构造失败反例或 Skills 夹具。
- 默认只读走查。不要点击“采用”“批准生效”“删除”“暂停”等会改变隔离状态的按钮；这些动作需单独作为可重复的写入验收执行。
- 发现问题时记录页面 URL、可见文案、预期、实际结果；不要用生产页面替代本清单的证据。

## 推荐顺序

### 0. 身份、历史与侧栏（5 分钟）

从 `/chat` 开始，确认用户名显示为 `primary`、助手状态为在线，并确认未出现 production/111 的账号冒充提示或内部 scope 标识。

检查会话侧栏：

1. 首屏可见聊天标题与 MG 的已知历史相符，且不混入 111 的“今日复盘”等会话。
2. 点击“加载更早”直至按钮消失，再核对标签：未分类 8、复盘 3、控盘度策略工具 3。
3. 普通侧栏共有 14 条可见会话；备份中另有 6 条已删除展示态，不应复活。
4. 任意打开一条历史对话并返回侧栏，确认选中态、标题和分组不丢失。

判失败：真实历史或标签缺失/错归属；出现 111 或其他 scope 的会话；页面要求用户理解 scope、checksum、run-basis 等内部术语。

### 1. 工作空间：内容、版本与生效（8 分钟）

从侧栏进入“工作空间”。当前真实数据只有一条“控盘度综合评分”内容对象；导航文案仍为“我的方法”，这是本轮需要你判断的产品命名问题。

方法线：

1. 卡片能一眼分辨当前采用版本、待确认版本、最近变更和绑定自动化数量。
2. 打开一个方法详情，依次检查版本时间线、版本 Diff、被任务使用和关联资料跳转。
3. 从关联资料进入“我的文件”，确认此处是资料查看入口，而方法内容只在“工作空间”编辑，没有两套编辑入口。
4. 返回方法页，确认“保存草稿”和“采用/生效”是不同状态、不同操作，不会让用户误以为保存立即改变运行行为。

Skills 线：

1. Skills 空列表应明确表达“当前没有”，不能被错误地呈现为加载失败。
2. 记录空状态是否足够解释，不要求验证不存在的安装、升级或版本比较流程。

判失败：任何“保存即生效”的暗示；方法/Skill 内容在文件页重复可编辑；任务绑定或关联资料无法解释来源与影响。

### 2. 自动化到失败处理的闭环（10 分钟）

依次进入“自动化任务”和“待处理”。这条线重点验收：真实 MG 自动化历史能否被理解；本轮不要求特定失败夹具。

1. 在自动化页打开带运行记录的任务，检查任务概览、运行历史、投递结果和关联事项四块信息是否足以回答“发生了什么、影响什么、现在怎样”。
2. 若存在待处理事项，打开一条并确认失败原因、累计次数、恢复状态和建议操作是用户语言，没有错误码、堆栈或 trace。
3. 若存在“让 Agent 解释并处理”入口，确认打开的会话围绕同一事项，不泄露内部日志，也不跳到无关历史会话。
4. 若存在“待确认改进”候选，确认其明确标注为草稿/待确认，显示适用范围、事实依据、预期改变和影响；本轮不点击批准或拒绝。

判失败：存在的失败只靠微信可见；问题会话没有绑定原事项；候选看起来已自动生效；页面以技术细节代替用户可理解的说明。

### 3. 我的文件与跨页导航（4 分钟）

从侧栏进入“我的文件”，随机打开一个与方法或自动化关联的资料。

1. 来源、关联自动化和报告归属可理解且可跳转。
2. 从文件进入方法/自动化，再返回文件，页面上下文和浏览路径不混乱。
3. 资料页没有把方法或 Skill 伪装成普通可编辑文件。

判失败：关联跳转断开；用户无法知道资料为何出现在这里；同一对象在多个页面有冲突的编辑入口。

### 4. 设置与隔离感知（3 分钟）

进入“设置”，只查看通知偏好及其文案。

1. 失败网页告知与微信提醒的关系清楚：关闭提醒不等于丢失网页事项。
2. 不出现生产账号、生产地址、真实微信会话或任何凭证。
3. 返回聊天页，确认导航仍可用，未因切页改变当前会话或身份。

判失败：隔离用户身份与生产身份混淆；页面暗示已经向真实微信发送；关闭通知被表述为关闭失败记录。

## 结论格式

每一条线给出一个结论：`通过`、`通过但有修订项`、`阻断`。

建议按下面格式反馈：

| 线 | 结论 | 页面/动作 | 观察到的事实 | 期望或修订项 |
| --- | --- | --- | --- | --- |
| 0 历史与侧栏 |  |  |  |  |
| 1 工作空间 |  |  |  |  |
| 2 失败处理 |  |  |  |  |
| 3 文件导航 |  |  |  |  |
| 4 设置与隔离 |  |  |  |  |

## 本轮不作结论的事项

- 真实微信送达与真实用户的长期使用反馈；隔离环境处于 OFFLINE 模式。
- 生产 schema 迁移、生产数据回填和发布后的运行观察。
- 系统/市场 Skill release 的真实安装升级体验；当前隔离数据没有真实 release。
