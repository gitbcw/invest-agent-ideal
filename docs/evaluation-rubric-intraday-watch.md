# 产出质量 Rubric：盘中盯盘简报（ED-P2 试点二）

状态：**v1 草案，待 owner 审定后启用**（2026-09-02 起草；owner 已确认试点选型，本文为执行稿）

## 一、定位与用途

- ED-P2 第二试点：对 dyk 盘中盯盘任务（交易日盘中每小时一窗、9:30–15:00 共 7 窗，2026-09-03 首轮评分时按生产 run 核实——非早期草案所记 9:55/14:30 两窗；`wechat_summary` 到点必推）的微信推送内容做**人工质量评分**；
- 与行业复盘 rubric 同构同纪律：只度量不触发修改；评分记录兼作 ED-P3 judge 校准样本。

## 二、评估对象与产出契约

- 产出形态：agent 生成的微信文本简报（个股行情 + 持仓相关简评），经 push 队列送达；
- 宇宙约束（2026-08-31 修复后）：**标的宇宙由服务端注入**（dyk 持仓 + 自选），简报只允许覆盖宇宙内标的——这是 W1/H1 维度的依据；
- 数据约束：行情须为当日盘中实时快照（工具直查），不允许以缓存陈值或记忆冒充；
- 交付语义：到点必推（无内容也推一条轻量说明）；**是否到点、是否送达不属本 rubric**（调度层，巡查覆盖），但采样时顺带核对 delivery 状态留档。

## 三、采样方式

- 每周评 **3-5 条**推送；分层：常规条 + 当周若有迟发/失败/巡查标注异常条则必含；
- 样本读取：只读——push_jobs 当周 dyk 名下 market-watch 推送的 message（评分必要的内容访问，遵循最小化：不外传、不整段摘录进公开文档）；
- 时点：每周一评上周；落档 `data/eval-rubric-scores/YYYY-WW-watch.jsonl`。

## 四、评分维度（三级锚点：2 达标 / 1 边界 / 0 不达标）

| 维度 | 定义 | 2 分锚点 | 0 分锚点 |
| --- | --- | --- | --- |
| W1 宇宙正确 | 标的全部在持仓/自选宇宙内 | 全部命中宇宙 | 出现宇宙外标的（幽灵个股） |
| W2 数据时效 | 行情时点为当日盘中，且简报标注了数据时间 | 时点明确且当日盘中 | 用旧数据冒充当日、无时间标注 |
| W3 信号质量 | 涨跌/异动描述与数值一致，提示有据 | 描述与数值自洽、提示可溯源 | 与自身数值矛盾、编造异动 |
| W4 完备性 | 持仓逐只覆盖（或明确说明缺席原因）；自选中触发关注的入选 | 持仓无遗漏 | 持仓遗漏且无说明 |
| W5 表达适配 | 微信短文本场景的可扫读性 | 关键信息前置、结构清晰、长度克制 | 长篇流水账、关键信号淹没 |

## 五、硬门槛（一票否决，不与维度分平均）

- **H1**：幽灵个股（宇宙外标的出现）——8-31 事故的回归哨兵；
- **H2**：编造数值、来源或异动；
- **H3**：冒充实时（以陈旧/记忆数据冒充当日盘中行情）。

任一命中 → 总评 fail，转 ED-P1 候选并核对受阻点登记。
