# 客户策略指标化统一路标

状态：v1（2026-09-03 起草，T-419 梳理落地件，owner 会话定稿）

本文档回答三个问题：**这个方向的终局是什么、现在在哪个阶段、下一步是什么**。它是"客户自有策略 → 系统内可计算指标 → 序列复现 → 信号自动化"方向的唯一现行路标；[`custom-formula-historical-screening-research.md`](./custom-formula-historical-screening-research.md)（2026-07-27 调研）的现状结论已被本文档取代，其方法论部分（支持等级、point-in-time、风险表）继续有效。

节奏约束（owner 2026-09-02 裁决，优先级高于本文档任何阶段建议）：本方向作为客户策略打磨的一部分**按需推进**，不设独立主线、不设里程碑压力。

## 1. 终局定义

以 mg 为第一样本，终局 = 客户策略从「文档 + 同花顺副图 + 自动化采集 Excel」**整体搬进系统**，四个要素：

1. **策略资产化**：客户的策略（如《控盘度综合评分》V1.2）成为系统内版本化、可计算的指标定义（`indicatorDefinitions` 中 `owner=customer` 的 expression/script 资产），不再是 Agent 照文档逐条执行；
2. **数据系统化**：策略依赖的通用数据（K 线、换手率、筹码分布等）由系统每日自动积累，覆盖策略计算所需窗口；
3. **序列可复现**：任一策略指标对任一股票池可回看 N 日序列——同花顺"副图叠加"的系统内等价物，多个策略指标可叠加对比（owner 2026-09-03 确认的终局基准）；
4. **信号自动化**：策略指标接入每日自动化管道，输出"进入关注区间 / 到达买点卖点"类信号，经现有 rule_alert / automation 推送交付。

到该状态时，客户的 Excel 与同花顺副图退役为可选习惯，而非必需环节。

## 2. 现状盘点（2026-09-03）

> 本节取代 7-27 调研 §3 的现状判断。变化最大的一条：**"筹码数据缺失导致无法承接"的前提已不成立**——`src/services/chip-distribution.ts` 提供基于换手率衰减的筹码分布代理模型（可算 WINNER 获利盘比例），并于 2026-08-23 经 BC-20260823-001 验证实时渠道可得。

| 层 | 已有资产 | 状态 |
| --- | --- | --- |
| 计算层 | 指标定义注册表 `indicatorDefinitions`：36 个内置指标（含 `CHIP_DISTRIBUTION`、`WINNER`——注明等价通达信函数），`formulaType` 支持 builtin/expression/script/manual_spec | 现役（server 启动 seed；rule_alert 跑在其上） |
| 计算层 | 复合指标引擎 L1 算子 / L3a 声明式 / L3b 沙箱脚本（含 isolated-vm 资源限制），沙箱已注入筹码算子 | 现役契约见 [`composite-indicator-system.md`](./composite-indicator-system.md)。修正旧说法：引擎**并未**随旧系统归档，mastra 仓内现役 |
| 计算层 | qsse-qlib MCP：表达式选股 + 回测（4 工具，interactive-only，默认关闭） | 生产在用（T-400 窗口 60 次真实调用） |

**主要缺口只有一个**：mg 的控盘度策略仍停留在「方法论文档 + Agent 执行」形态，尚未翻译成指标体系里的一个客户指标定义。引擎、数据、管道三层的零件都在。

## 3. 阶段划分

```text
S0 数据与管道基础          ✅ 已完成（上表全部）
S1 mg 控盘度资产化试点     ⬜ 未启动（当前所在位置：S0 完成、S1 待裁决）
S2 信号自动化              ⬜
S3 多客户通用化            ⬜
```

- **S1 控盘度资产化试点**：把《控盘度综合评分》V1.2 翻译为可计算指标定义；用已积累的通用数据复现 60 日序列，与 mg 的 Excel 历史行/同花顺副图对照，完成口径分级（代理/兼容）判定。这是对"序列可复现"终局的第一次实证。
- **S2 信号自动化**：指标定义接入每日管道（automation/rule_alert），对自选池输出关注区间/买卖点信号。
- **S3 通用化**：多客户策略资产与公式版本管理惯例固化；专有精确数据采购（如 Tushare `cyq_*`）仅在真实客户公式被代理口径阻塞时按 7-27 调研 §7 阶段 2 条款触发，不预先建设。

## 5. 待验证与待决策

1. **60 日窗口是否足够**：控盘度公式各子项的实际历史窗口需求 vs 当前 60 日数据积累（不足则先扩窗口再谈复现）；
2. **口径偏差度量**：chip-distribution 代理值与 mg 同花顺口径的偏差量级，决定支持等级标"代理计算"还是"兼容支持"（沿用 7-27 四级框架）；
3. **S1 实现载体**：L3a/L3b 复合指标体系 vs qsse-qlib 表达式（两者都现役，选型在 S1 启动时裁决）；
4. **策略资产归属**：客户指标定义按 workspace 用户资产管理（沿用模板/资产红线），owner=customer 的确认与告知门槛沿用 composite-indicator-system 契约。
