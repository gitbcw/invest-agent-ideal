# Experimental MVP 使用说明

本文档用于第一个实验版本试用。当前版本目标是跑通投资助手闭环，不代表最终策略能力。

当前交互方式已经切换为 Agent Runtime：用户可以用自然语言对话，不需要记命令格式。下面示例只是推荐说法，不是固定指令。

## 当前支持能力

- 持有股票池维护和查询。
- 自选股添加、移除和查询。
- 股票行情和基础技术指标分析。
- 行业/概念选股问答。
- 每日复盘和明日预案。
- 单股交易预案：支撑位、压力位、目标位、止损位、策略备注。
- 盘中基础提醒。
- 提醒事件记录。
- 提醒反馈记录：客户可在微信中标记提醒有用、无用或误报。

## 微信指令示例

### 持仓

```text
我持有 000001 和 600000
帮我更新持仓，我现在持有 000001、600000
我现在持有赣锋锂业、盛新锂能和赛轮轮胎
我的持仓
不再持有 000001
把刚才那两个移除
```

实验版持仓主要用于确定复盘和盘中提醒范围，不要求填写成本和数量。如果用户愿意记录成本，也可以发送 `更新持仓 000001 成本 10.50`，但盘中提醒不会依赖仓位成本判断。

### 自选股

```text
把阳光电源和宁德时代加入自选
把 000001 加入自选，理由是来自选股报告
自选列表
自选 000001
移除 000001
```

### 行情和分析

```text
000001
看看 000001
分析一下 000001
```

### 选股问答

```text
帮我选 芯片行业
AI 概念有什么股票
新能源汽车板块分析
```

输出会包含行业分析、初筛公司、精选候选、自选股建议和数据缺口说明。

### 提醒

```text
设置提醒 000001 涨跌幅 3
设置提醒 000001 换手率 5
设置提醒 000001 量比 2
设置提醒 000001 放量突破 1.8
设置提醒 000001 跌破支撑
查看提醒列表
关闭提醒 000001
```

提醒会结合自选股、持仓股和最近每日预案。若没有预案，会标注“未找到预案”。

注意：提醒规则和监控概览尚未完整接入 Agent Runtime。当前如果询问“我做了哪些监控”，系统可能只能基于产品能力直接说明，下一步计划新增真实监控概览工具。

收到提醒后，可以直接反馈提醒质量：

```text
000001 提醒有用
000001 提醒无用
000001 误报
提醒有用
```

带股票代码时，会优先标记该股票最近一条提醒；不带代码时，会标记最近一条提醒。反馈会进入复盘记录，用于后续判断哪些指标有效、哪些指标容易误报。

### 交易预案

```text
设置预案 000001 支撑 10 压力 12 目标 14 止损 9.5 备注 低位观察
更新预案 000001 止损 9.6
更新预案 000001 目标 14.5 备注 放量突破后分批减仓
预案 000001
预案列表
删除预案 000001
```

交易预案优先级高于每日复盘自动生成的临时预案。盘中巡检会优先使用人工设置的支撑位、压力位、目标位和止损位。

### 复盘

```text
每日复盘
周复盘
查看 2026-05-24 复盘
```

每日复盘会生成明日预案，包括支撑位、压力位、观察条件和风险点。

## 当前实验策略能力

当前版本主要使用以下可获取数据：

- 实时价格。
- 涨跌幅。
- 成交量。
- 换手率。
- MA 均线。
- MACD。
- 近 20 日支撑位和压力位估算。
- 人工设置的交易预案。

## 当前已知限制

- 尚未接入完整财经新闻、公告和研报源。
- 尚未接入可靠的主力控盘、筹码集中度、大单净流入数据。
- 主力相关判断只能作为间接观察，不能作为确定结论。
- 行业和基本面分析主要依赖 AI 对公开信息的理解，缺少结构化财务数据库验证。
- 不支持自动交易。
- 不做仓位控制和自动交易；持仓数量、成本只作为可选备注。
- 不支持完整多模态输入。
- 不支持订阅支付。

## 需要继续补充的资料

- 三本投资相关书籍。
- 技术面思维导图。
- 行业分析信息源清单。
- 市场容量、占有率、增长空间、研发费用率等指标细则。
- 常用财经公众号清单。
- 当前自选股截图。
- 当前持仓或模拟持仓。
- 成功和失败交易案例。
- 加仓、减仓、止损、止盈规则。

## 建议试用流程

1. 先告诉助手当前持有哪些股票。
2. 添加 3-5 只自选股。
3. 发起一次行业或概念选股问答。
4. 将报告中的候选股加入自选。
5. 生成每日复盘。
6. 第二天观察盘中提醒。
7. 收到提醒后直接反馈“提醒有用 / 提醒无用 / 误报”。
8. 收盘后查看复盘，观察哪些提醒有效、哪些规则需要调整。

## 当前重点测试话术

```text
看一下我现在的持仓有哪些
再把这个池子里添加两个阳光电源和宁德时代
算了，把它移除吧
目前我做了哪些监控？监控指标是什么？
```

前三句已通过本地 Agent Runtime 测试。第四句是下一步重点优化点：需要新增真实监控概览工具。
