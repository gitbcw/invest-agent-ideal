# 数据源与指标可行性参考手册

> 创建于 2026-05-28。当客户提出具体指标需求时，参照本文档评估可行性，避免重复调研。
> 本文档基于实际测试和对接经验编写，非理论汇总。

---

## 一、已接入的免费数据源

### 1. 腾讯行情 API（主力数据源）

**稳定性：高** — 长期可用，无反爬机制，响应格式稳定。

| 接口 | 用途 | 数据颗粒度 | 频率限制 |
|------|------|-----------|---------|
| `qt.gtimg.cn/q=` | 实时报价 | 3 秒级快照（Level-1） | 无明确限制，合理使用即可 |
| `web.ifzq.gtimg.cn/appstock/app/fqkline/get` | 日 K 线 | 日线，前复权，最多约 120 日 | 同上 |
| `ifzq.gtimg.cn/appstock/app/kline/mkline` | 分时 K 线 | 5 分钟线，最多 48 根 | 同上 |
| `smartbox.gtimg.cn/s3/` | 股票搜索 | 模糊匹配代码/名称 | 同上 |

**实时报价字段**（`qt.gtimg.cn`）：
- 价格：现价、昨收、今开、最高、最低、涨跌额、涨跌幅
- 量能：成交量（手）、成交额（万元）、换手率
- 盘口：五档买卖量（买一到买五、卖一到卖五量），可算买卖量差
- 时间戳

**日 K 线字段**：日期、开盘、收盘、最高、最低、成交量。

**5 分钟 K 线字段**：时间、开盘、收盘、最高、最低、成交量、成交额。

**能算什么**：
- MA（均线）、MACD、KDJ、RSI、布林带 — 日 K 线足够
- 量比（当日累计量 vs 同期 5 日均量） — 日 K 线 + 实时量
- 换手率异常 — 实时报价直接提供
- 放量滞涨/滞跌 — 5 分钟 K 线，量价背离检测
- CYW 主力控盘（简化版） — 日 K 线即可，见下文「可计算指标」
- 筹码分布近似 — 日 K 线衰减加权法，见下文

**不能做什么**：
- 逐笔成交（tick 级别）— 需要 Level-2
- 分钟级以下 K 线（1 分钟）— API 不提供
- 买卖盘挂单明细 — 仅有五档汇总量，无逐笔委托

### 2. 东方财富资金流 API

**稳定性：中** — 部分端点有反爬保护。

| 接口 | 用途 | 状态 |
|------|------|------|
| `push2his.eastmoney.com`（K 线历史） | 分钟/日 K 线 | **不稳定**：首次可能成功，后续返回空响应，反爬机制 |
| `fflow.eastmoney.com`（资金流向） | 主力/超大单/大单/中单/小单净流入 | **可用**：已接入并稳定运行 |

**资金流字段**（`fflow`）：
- 主力净流入（万元）、超大单净流入、大单净流入、中单净流入、小单净流入
- 各分类的净流入额和净流入比例
- 日频数据

**注意事项**：
- 并发请求需做 worker pool 限制（当前 max 5），否则会被限流
- `push2his` 端点不可依赖，已改用腾讯 API 替代

## 二、收费数据源

### Level-2 行情（券商提供）

**价格**：约 60 元/年（各券商不同，部分开户赠送）

**额外获得的数据**：
- 逐笔成交（tick 级别，约 3 秒内所有成交）
- 十档买卖盘（Level-1 只有五档）
- 逐笔委托队列
- 成交明细中的主动买/主动卖标记

**适用场景**：
- 精确的主力买卖方向判断（主动大买单 vs 主动大卖单）
- 分时逐笔量能分析
- 精确的筹码分布计算（基于真实成交价位）
- 大单追踪、主力行为分析

**接入方式**：
- 通达信/同花顺 Level-2 插件（本地数据）
- 券商量化接口（如 QMT、PTrade）
- 第三方数据服务商（如 Tushare Pro 积分制、聚宽、万得）

### 第三方数据平台

| 平台 | 特点 | 价格 |
|------|------|------|
| Tushare Pro | 日 K、分钟 K、资金流，积分制 | 免费额度有限，高级需捐助 |
| 聚宽 JoinQuant | 量化研究平台，数据较全 | 研究环境免费，实盘收费 |
| 万得 Wind | 金融终端标准数据源 | 机构级定价（年费数万） |
| AKShare | 开源 Python 库，聚合多源 | 免费，但稳定性依赖源站 |

## 三、可计算指标（基于免费数据）

以下指标仅需日 K 线（OHLCV）或 5 分钟 K 线，无需额外数据源。

### CYW 主力控盘（通达信公式）

**数据需求**：日 K 线（12 日以上）

**通达信常见公式原理**：
1. 取 12 日价格区间，将当日价格归一化到 [0, 1]
2. 以归一化值为权重，对成交量做加权分类：高位放量视为"卖出刺激"，低位放量视为"买入刺激"
3. SMA 平滑处理，得到 CYW 值
4. CYW > 0 表示主力控盘偏多，< 0 偏空

**我们能做的**：用日 K 线实现上述公式，输出 CYW 数值和方向判断。

**局限**：
- 通达信官方 CYW 使用"神经元模型"（具体参数未公开），开源公式是近似
- 无法区分主动买/主动卖（需 Level-2 逐笔数据）
- 仅基于日线，盘中无法实时更新

### 筹码分布（CYQ）近似

**数据需求**：日 K 线（60 日以上）

**方法**：衰减加权法
1. 对每个交易日，假设成交量均匀分布在当日最高价~最低价区间
2. 越早的交易日权重越低（三角衰减，半衰期约 20 日）
3. 累积所有交易日贡献，得到每个价位的筹码量

**我们能做的**：用日 K 线计算筹码分布直方图，估算支撑位/压力位。

**局限**：
- 假设成交量均匀分布在当日价格区间（实际可能集中某一价位）
- 无法获得真实成交价位分布（需 Level-2 逐笔）
- 长期横盘股的筹码分布准确性较低

### 放量滞涨/滞跌

**数据需求**：5 分钟 K 线（48 根 ≈ 4 小时）

**方法**：
1. 计算当日已过时段的平均成交量
2. 检测最近 N 根（默认 6 根 = 30 分钟）K 线
3. 触发条件：成交量 > 均量 × 倍数（默认 3）且 振幅 < 阈值（默认 0.5%）
4. 滞涨 = 放量但价格不涨（可能主力派发），滞跌 = 放量但价格不跌（可能主力吸筹）

**已实现**：`src/scheduler/alert-check.ts` 中的 `volume_price_divergence` 信号。

### 经典技术指标

以下指标仅需日 K 线，标准公式即可计算：

| 指标 | 计算复杂度 | 说明 |
|------|-----------|------|
| MA（均线） | 低 | 5/10/20/60 日常用 |
| MACD | 低 | 12/26/9 参数 |
| KDJ | 低 | 9/3/3 参数 |
| RSI | 低 | 6/12/14 日常用 |
| 布林带 | 低 | 20 日 + 2 倍标准差 |
| 量比 | 低 | 当日累计量 / 同期 5 日均量 |
| OBV | 低 | 累计量能 |
| ATR | 低 | 真实波幅均值 |

## 四、做不到的事（需要额外数据或成本）

| 需求 | 缺什么 | 解决方案 |
|------|--------|---------|
| 逐笔成交分析 | Level-2 数据（~60 元/年） | 接入券商量化接口 |
| 精确的主力买卖方向 | 逐笔数据中的主动买/卖标记 | 同上 |
| 实时筹码分布 | 每笔成交价位 | Level-2 或第三方数据商 |
| 1 分钟 K 线 | 腾讯 API 不提供 | 东方财富 push2his（不稳定）或 Tushare |
| 板块资金流向 | 东方财富板块接口（未测试） | 需额外调研 |
| 龙虎榜数据 | 需要专门接口 | 东方财富/同花顺有公开页面 |
| 融资融券数据 | 需要专门接口 | 交易所官方公布 |
| 期权/期货数据 | 完全不同的数据源 | 需单独对接 |

## 五、API 稳定性经验

| 数据源 | 经验 |
|--------|------|
| 腾讯行情 `qt.gtimg.cn` | 稳定，GB18030 编码，需设 Referer |
| 腾讯日 K `web.ifzq.gtimg.cn` | 稳定，JSON 格式，前复权数据 |
| 腾讯 5 分钟 K `ifzq.gtimg.cn` | 稳定，JSON 格式 |
| 东方财富资金流 `fflow` | 可用，需控制并发（≤5） |
| 东方财富 K 线 `push2his` | **不可靠**：反爬机制，Node.js fetch 会收到空响应 |
| 腾讯搜索 `smartbox` | 稳定，GB18030 编码 |

**教训**：东方财富的行情类接口有反爬保护，不适合作为主数据源。资金流接口目前可用但需做好降级预案。优先使用腾讯 API。

## 六、快速决策表

当客户提出新指标需求时，按此表快速判断：

| 指标类型 | 需要什么数据 | 我们有没有 | 能不能做 |
|----------|-------------|-----------|---------|
| 基于 OHLCV 的技术指标 | 日 K 线 | ✅ 有 | ✅ 直接做 |
| 基于成交量的分析（日线） | 日 K 线 | ✅ 有 | ✅ 直接做 |
| 基于分时量价的信号 | 5 分钟 K 线 | ✅ 有 | ✅ 直接做（精度有限） |
| 资金流向异动 | 东方财富资金流 | ✅ 有 | ✅ 已接入 |
| 主力控盘类（CYW 近似） | 日 K 线 | ✅ 有 | ✅ 公式实现 |
| 筹码分布（近似） | 日 K 线 | ✅ 有 | ✅ 衰减加权法 |
| 精确主力行为分析 | Level-2 逐笔 | ❌ 没有 | 💰 ~60 元/年 |
| 1 分钟级 K 线 | 分钟数据源 | ❌ 腾讯不提供 | ⚠️ 需另找源 |
| 板块/行业级数据 | 板块接口 | ❌ 未接入 | ⚠️ 需额外调研 |
