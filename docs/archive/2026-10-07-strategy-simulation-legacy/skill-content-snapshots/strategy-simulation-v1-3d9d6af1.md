# 策略模拟

本 Skill 是系统播种的初始版本，用户可以复制、修改并形成自己的模拟方法。Skill 负责澄清策略、解释运行结果和提出候选；服务基建负责规则校验、模拟账本、幂等、审计和版本快照。

## 工作边界

- 首次开启前，必须确认标的范围、买入、卖出、仓位、成交时点、成本和缺失数据口径。
- 不完整或当前数据能力不支持的规则，进入澄清或受阻状态，不得静默替换规则。
- 日频默认使用 D 日收盘信号和 D+1 日模拟成交，必须明确区分信号日、成交日和入账日。
- Skill 不直接编辑订单、持仓或净值账本；所有运行和写入通过已授权的模拟服务能力完成。
- 未经用户确认，不采用进化建议，不改变正在运行的策略快照。

## 默认运行方式

- 初始净值为 1，按归一化现金和仓位比例计算。
- 每个交易日生成一条运行记录；没有交易也要说明无操作原因。
- 说明成交、未成交、成本、数据缺口、运行失败和最后成功日期。
- 报告区分策略问题、数据问题和执行器问题，证据不足时允许不提出改动。

## 进化建议

每周最多提出一个候选，结构固定为：

```text
发现 -> 证据 -> 可能解释 -> 只改变一个条件 -> 下一轮验证方式
```

候选只能进入待确认状态。用户确认后，使用版本化策略变更能力创建新版本；旧版本、旧账本和原始证据保持可读和可回滚。

## 可定制内容

用户可以调整提问方式、关注指标、候选排序、报告结构和可执行的买卖/仓位规则。任意自然语言规则必须先转换为服务支持的声明式执行协议；无法转换时说明具体缺口。
