# 新 Onboarding 设计稿

状态：v2（2026-08-14），按用户裁决修订——策略包进引导、复盘盯盘默认配置不显选、Portal 为主
前置：预设模型已落地（[preset-system-design.md](./preset-system-design.md)；策略包 = kind:"strategy" 预设，策略实体库已就位）

## 1. 设计原则

- Onboarding 完成**最小可用闭环**：身份 → 持仓 → 策略 → 节奏默认
- **Portal 为主入口**（产品有门槛，微信不做初始引导，只做后续使用）
- 复盘/盯盘配置：**默认给初始配置**（低打扰预设静默应用），告知可选、可改；用户没玩懂之前不强迫选择
- 策略：录入自有策略 **或** 选一个策略包（二者其一，可都跳过后续补）

## 2. 流程（Portal 向导，四步）

```
① 身份就绪（自动）：登录即有 scope 与项目根
② 持仓录入（必做）：截图/CSV/口述 → 草案 → 确认落库
③ 策略（可选其一）：
   ├─ 选策略包（推荐展示：如 趋势跟踪包/价值回归包，各自带说明）
   ├─ 录入自有策略（表单/对话式描述 → 策略实体）
   └─ 跳过（后续在策略页补）
④ 节奏默认（一步告知不选择）：
   "已为你启用默认配置：交易日收盘复盘 + 盘中只推例外。可随时在任务页调整或关闭。"
   = applyPreset("low-disturbance-review") 静默应用 + 可视化告知
完成：任务页立即可见 4 个任务（可暂停/调整）
```

## 3. 策略包（本次新增重点）

- 复用预设对象模型 `kind: "strategy"`：内容 = 一组交易策略模板（写入策略实体库 `tradingStrategies`）+ 可选节奏建议
- 首批建议 2 个包（从现有策略模板提炼）；`applyStrategyPack` 与 `applyPreset` 同一机制（一个写策略库、一个建任务）
- Portal 策略页常驻"策略包"入口（后期可组合：策略包 × 节奏）

## 4. 工具面映射（C1 收缩依据，v1 判定不变）

draft 三件套保留（②持仓草案流）；六个步骤类工具移除（③④由选包/静默预设承接）；`confirm_portfolio` 保留。工具面目标 50 → 44+。

## 6. 已裁决点（原 §7 关闭）

- D17：截图识别与对话式策略描述不设专项（模型原生能力 + 普通对话即可）

- 低打扰预设：静默默认，不进初始选择；玩懂后 Portal 可换/可关
- 裸框架：不作为初始选项（默认给配置）；后续可经任务页清空实现同等效果
- 微信：不做初始引导；新用户在微信侧只收到"请先到 Portal 完成初始化"的轻指引
