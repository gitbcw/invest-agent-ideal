## 画像模板(6 维度)

每个画像必须填齐:

1. **基础档案**:年龄、职业、投资年限
2. **知识储备**:K 线/基本面/资金流/宏观 每项 1-5 分
3. **互动偏好**:句式、主动/被动、试错/谨慎
4. **投资风格**:保守/平衡/激进 + 单仓上限
5. **时间投入**:每天看几次、是否盘中盯
6. **对 AI 的信任度**:高/中/低 + 触发因素
7. **流失触发点**(关键!):什么样的体验会让他取关

## 旅程 7 个关键时刻

| 时刻 | 关注点 |
|---|---|
| T0 扫码绑定 | 静默期、欢迎语 |
| 首次对话 | 识别新用户、引导清晰 |
| 首次配置 | 30 秒看到价值 |
| 首条推送 | 信息密度、差异化 |
| 沉睡期 | 低打扰持续触达 |
| 沉睡唤醒 | 反向触达、挽回 |
| 闭环建立 | 复盘 → 观点 → 回测 |

## 输出方式(默认不落盘)

每次模拟**直接在对话里输出**,不写文件。挑出不合理点 + 给改进建议,用户看完没意见就默认执行,有意见直接说。

输出结构(对话内):

```
- 简短开场:用 X 视角走完 7 个时刻,挑出 N 条不合理点,致命的 Y 条
- 每条三段式:
  - 现状:文件:行号 + 当前行为
  - 为什么对画像不合理:画像视角的主观感受
  - 改进建议:具体改动 + 工作量预估
- 末尾:P0 / P1 / P2 分档汇总
```

**不输出**:总分、每时刻星级、流失风险等级、[用户裁决] 空位。除非用户明确说"保留这份报告",否则不写文件。

## 默认执行契约

挑完不合理点 + 输出完,**不追问"你裁决一下"**。用户的沉默 = 同意 = 进入执行:

- 涉及 prompt/skill → 直接改 `.codex/skills/*/SKILL.md` 或 `src/prompts/*`
- 涉及代码逻辑 → 写进当前 source-of-truth 文档或对应任务记录；历史方案只放 `docs/archive/`
- 涉及产品设计 → 写进本目录 README 的"待解决问题"
- 改完之后**重跑同画像**,对比效果
