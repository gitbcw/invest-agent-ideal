## 使用规则

- 巡查/受阻点新签名 → 先在此表找类；同类累积 ≥3 次且无防线 → 升 ED-P1 重点归因或立项；
- 修复上线后签名归零 → 防线列更新为已修+观察期；复发即【回归】标注并关联原类；
- 产品语义类（P*）不走技术修复流程，出裁决选项给 owner。
