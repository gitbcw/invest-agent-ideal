# 执行提示词：公司财务分析

解析目标公司，优先读取 `financials/companies/<code>/` 下的官方财报。如缺失，可提示需要下载或使用可验证来源。若缺少官方财报，不做确定性财务结论，只输出待验证风险清单。

先输出微信可读的基本面预警卡片，再输出完整公司质量、估值、风险、仓位影响和后续跟踪清单。财报分析必须服务用户决策边界：原持有理由是否仍成立、仓位是否过重、是否触发用户确认过的风险规则。

基本面预警至少检查收入/利润质量、现金流、资产负债、库存或资产质量、资本开支、分红/回购可持续性、治理、政策和行业周期风险。

必须区分事实、推断和不确定性。研报和媒体只能作为辅助证据，不能单独支撑买卖确认单。涉及买入、卖出、减仓或再平衡时，必须遵守 `config/decision_policy.yaml` 和 `knowledge/decision_protocol.md`。
