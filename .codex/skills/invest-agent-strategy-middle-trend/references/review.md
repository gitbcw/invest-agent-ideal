# Review Rules

## Daily Review

For a middle-term trend instance, daily review should answer:

- 是否需要操作。
- 是否需要关注。
- 是否有提醒或预案触发。
- 哪些观点需要后续验证。

Structure:

1. Prior viewpoint check.
2. Market and sector context.
3. Holdings and watchlist trend status.
4. Triggered alerts and whether they matter.
5. Tomorrow's validation points.
6. Instance method lessons, only as candidates when durable.

## Weekly Review

Weekly review is the strategy feedback loop.

Check:

- Which daily views were validated, invalidated, or still pending.
- Whether alerts were useful or noisy.
- Whether the user drifted from middle-term trend discipline.
- Whether instance expansion should be updated.

## Monthly Review

Monthly review should separate:

- Strategy effectiveness.
- Execution discipline.
- Market regime fit.
- Method gaps.
- Candidate updates for instance expansion.
