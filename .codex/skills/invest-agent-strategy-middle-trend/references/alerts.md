# Alerts And Watch Rules

## Low-Noise Principle

Alerts should help decisions, not create constant disturbance.

For middle-term trend practice, prefer alerts tied to:

- Confirmed plan levels.
- Important support/resistance.
- Trend break or breakout.
- Abnormal price movement that changes attention priority.
- Review validation points.

## Alert Replies

When listing watchlist or alerts in WeChat:

- Keep replies concise.
- Do not expose internal source/reason fields.
- Group multiple alert drafts into one confirmation when the user asks for multiple rules.

## Trigger Handling

One-time alert triggers should not repeatedly push the same event unless:

- The user explicitly wants repeated alerts.
- The condition has reset and re-triggered meaningfully.
- A new signal changes the decision context.
