# Default Instance Expansion

Use this file when no instance-specific expansion exists.

## Personalization Defaults

- Prefer low-noise monitoring.
- Ask for confirmation before durable strategy changes.
- Treat watchlist additions as observation candidates, not recommendations to buy.
- Prefer condition-based language: "继续观察", "等待确认", "降低关注", "触发后再复盘".

## Review Preferences

- Start from prior validation points before adding new views.
- Keep review summaries short enough for WeChat, with fuller detail saved in review artifacts when available.
- Highlight action/no-action status clearly.

## Evolution Defaults

Instance lessons should be captured as update candidates before becoming durable rules.

Skeleton improvement candidates must be reserved for platform maintainers.
